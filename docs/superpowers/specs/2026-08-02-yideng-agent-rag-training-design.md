# 一灯 Agent：课程知识、开发执行与 Qwen3 RAG 训练综合设计

日期：2026-08-02

## 1. 决策摘要

将原“一灯跨平台学习与开发 Agent”与课程作业“RAG 与 Agent 编排”合并为一个产品、一个仓库节点和一套验收链路。

最终产品是离线优先的一灯 Agent：它既是课程知识助理和面试教练，也是架构顾问与可执行的软件开发 Agent。Qwen3 QLoRA 用于学习稳定行为、教学表达和任务边界；完整课程事实由可增量更新的 RAG 知识库提供；个人长期记忆与事实知识分离；Codex、Claude Code 和 Cherry Studio 通过薄适配层调用同一个本地 Agent Core。

本设计是 `course-homework` 中该综合任务的正式真源。此前的 Qwen3 训练设计和“一灯学习笔记”仓库中的 Agent 设计保留为历史依据，不再单独推进。

## 2. 作业身份与实际实现

老师原始作业名称保持为 **RAG 与 Agent 编排**。原始必做项包括维修 Markdown、向量数据库与向量模型、Mastra 摄取、带 Rerank 的 RAG Agent、Mastra Client 前端和 LangGraph 编排器。

实际实现使用严格只读的“一灯学习笔记”作为主要课程知识源，并增加一个小型、原创、可公开验证的维修知识兼容语料，用于证明原题场景仍能运行。增强项使用至少 Qwen3-8B 级指令模型，在已核验的 NVIDIA CUDA 环境完成正式 4-bit NF4 QLoRA，最终迁移为 GGUF/Ollama 在 M5 24 GB Mac 上验收。

## 3. 目标

1. 课程与面试问题先给大白话主线，再按优先级展开关联知识网络、学习顺序、面试表达和常见追问。
2. 架构问题先给推荐方案，再说明取舍、成本、安全、失败路径和验收方法。
3. 执行型任务能读取项目、修改代码、运行测试并用可观察证据完成交付。
4. 需求不足时自动进入 `grill-me`；信息足够时自主结束追问并开始；连续三轮仍缺关键输入时公开假设后继续。
5. 当前官方资料优先于历史课程说法，并允许主动补充外部知识。
6. 联网核验后的官方事实只以最小、结构化、可复核的知识单元写入本地 `verified-external`。
7. 学习笔记变化自动触发增量索引，不重建无关内容。
8. 长期保存学习进度、薄弱点、面试表现和项目背景，并允许查看、更正、删除和导出。
9. Codex、Claude Code、Cherry Studio 和 Ollama 共享同一个本地知识、记忆与行为核心；断网后核心问答和本地开发仍可使用。
10. 完成可复现、可重载、可对比评测的 Qwen3 正式 QLoRA，并保留完整训练证据。

## 4. 非目标

- 不把完整课程笔记、逐字稿、训练集、Adapter 或模型权重公开。
- 不把全部课程事实强塞进模型参数；微调负责行为，RAG 负责知识。
- 不用低质量同义改写凑数据数量。
- 不让 Codex、Claude Code 或 Cherry Studio 各自维护一份分叉的业务规则或知识副本。
- 不在 Mac 上安装或执行 CUDA 训练栈。
- 不在未经用户当次明确确认时创建、启动或扩大付费云资源。
- 不把搜索摘要、模型推测或整段聊天回复直接写入已验证知识层。

## 5. 总体架构

```text
Codex / Claude Code / Cherry Studio / OpenAI-compatible clients
                              │
                         platform adapters
                              │
                       Yideng Agent Core
       ┌──────────────┬───────┴────────┬──────────────┐
       │              │                │              │
 route + grill-me  RAG + rerank    personal memory  controlled tools
       │              │                │              │
       │      ┌───────┼────────┐       │        files/Git/tests/browser
       │      │       │        │       │
       │   course  verified  generated │
       │            external            │
       └──────────────┬─────────────────┘
                      │
       Ollama Qwen3 adapter/GGUF + BGE-M3 embedding
```

Agent Core 是行为协议、知识接口、记忆接口和工具权限的唯一真源。平台适配层只负责触发方式、协议转换和平台安全约束。

## 6. Agent 行为协议

### 6.1 请求路由

请求可组合以下模式：

- `learn`：课程解释、知识网络和学习路径；
- `interview`：面试回答、追问、评分与薄弱点更新；
- `architecture`：方案、取舍、风险和验证；
- `execute`：读取项目、实现、测试和交付。

### 6.2 grill-me

只有目标、交付物、关键约束或验收标准的缺失会显著改变结果时才追问。每轮选择信息价值最高的问题。当信息足够且剩余不确定性不会改变主要方案时，Agent 必须自主开始。连续三轮仍无法获得关键输入时，Agent 列出假设、风险和可逆点，然后沿用户方向完成成熟结果。

### 6.3 知识回答

课程资料优先。课程未覆盖时允许直接使用通用知识，不强制在自然语言回答中增加“非课程内容”标识；但内部检索记录仍保留来源与可信度。精确版本、实时事实、原文引用或高风险问题没有可靠证据时不得编造。

事实冲突优先级为：当前官方资料与规范、当前项目运行证据、课程总结、课程转写或历史演示、Agent 推导。

### 6.4 开发执行

在用户任务范围内可自主执行本地、可恢复的读取、修改、构建和测试。完成必须由测试、构建、运行结果或可视证据支持。创建或扩大付费云资源、生产破坏性写入、凭据外发和不可逆版本控制操作必须遵守额外确认边界。

## 7. 知识、索引与记忆

逻辑分层固定为：

```text
knowledge/
├── course/              # 只读课程来源及其派生索引
├── verified-external/   # 官方证据支持的最小知识单元
└── generated/           # 主题地图、术语关系与检索元数据
memory/
└── personal/            # 学习、面试和项目记忆，与公共事实隔离
```

RAG 使用 Qdrant 向量检索、BGE-M3 Embedding、本地 BM25、Reciprocal Rank Fusion、元数据过滤和强制 Rerank。Mastra 实现摄取、检索、重排、回答和质量检查；Mastra Client 展示回答、引用、检索片段、状态与失败原因；LangGraph 按同一数据契约实现状态编排、重试、持久化和人工升级。

索引记录文件路径、内容 Hash、修改时间、解析器版本和 Embedding 版本。新建、修改、移动或删除只更新受影响分块；失败时保留上一版索引；Embedding 变化创建新索引版本，不混用向量。

个人记忆只保存有长期价值的信息，区分用户事实、Agent 观察和推断，并带来源会话、时间和置信度。事实知识不得通过个人记忆污染。

## 8. 官方知识回写

联网查询只依赖直接支持结论的官方文档、规范、源码或公告。回答完成后，仅把与现有知识网络相关、可独立验证的最小知识单元写入 `verified-external`，至少保存：稳定 ID、claim、官方 URL、发布方、检索日期、适用版本或时点、内容 Hash、相关课程、状态和复核期限。

官方页面未提供更新时间时保持为空，不得推测。结论变化时创建新版本并把旧记录标为 `superseded`。网络失败或只能取得搜索摘要时不写入已验证层。离线时使用最后核验版本，并保留最近核验日期供界面查看。

## 9. 训练数据契约

### 9.1 smoke 与正式训练分离

- 现有 `rag-sft-20260802-v1` 共 63 条：50 train、7 validation、6 frozen test，只用于 smoke。
- smoke 的目的仅是验证模型、数据、CUDA、训练、Adapter 导出与重载链路，不能作为正式训练完成证据。
- 正式第一版的数据 release 必须包含至少 **300 条 train**；validation 与 frozen test 独立且不计入 300。
- 质量允许时推荐约 1000 条 train；1K–10K 只增加真实覆盖和边界，不做机械扩写。

### 9.2 数据内容

训练样本覆盖课程教学与知识网络、面试问答与追问、架构取舍、开发执行、`grill-me`、官方事实优先、增量索引、个人记忆、RAG/Rerank、工具权限、付费确认、故障诊断和错误纠正。

每条样本必须是原创派生表达，记录可追溯来源标识，但不包含长段课程原文、真实姓名、联系方式、凭据、账户、私有路径、重复转写、生成物或临时文件。

### 9.3 质量与泄漏

正式 release 必须通过 schema、精确与近似去重、来源追溯、隐私扫描、凭据扫描、内容质量审核、分组划分和数据泄漏检查。相同来源、同一知识点的近似问题和答案不得跨 train、validation 与 frozen test。

## 10. Qwen3 CUDA 训练

候选基座至少为 Qwen3-8B 级指令模型。实际模型 ID、精确 revision、Tokenizer 和 chat template 必须在联网下载前核验并冻结；不得根据名称猜测具体变体。

付费启动前再次展示候选设备、费率、余额、上限和停止时间并取得明确确认。启动后第一步只核实实际 GPU、显存、驱动、CUDA、系统内存、磁盘和已有模型；在这些证据取得前不选择最终 batch、上下文长度或 LoRA 容量。

正式训练使用 4-bit NF4 QLoRA，保留精确 base revision、Tokenizer、chat template、随机种子、完整配置、train/validation loss、训练时长、峰值显存、checkpoint、Adapter 文件清单和 SHA-256。

先完成 8B smoke 和正式 8B 基线，再优先提升数据质量、覆盖、上下文和 LoRA 容量。只有远程显存、训练时限和 M5 24 GB 部署验证允许时才评估 14B；32B 不作为第一版目标。

## 11. 模型评测与 Mac 迁移

Adapter 必须用完全一致的基座、Tokenizer 和 chat template 重新加载。使用同一冻结测试集比较 base 与 adapter，至少评估概念正确性、教学清晰度、知识网络组织、`grill-me` 行为、开发步骤、事实边界和安全边界。只有出现可解释提升且无明显能力退化才通过。

训练完成后保留原始 Adapter，再按可复现流程合并模型、转换 GGUF、创建 Ollama 模型，并在 M5 24 GB Mac 做真实推理、离线问答、内存占用、响应速度和回归验收。Mac 不执行 QLoRA。

## 12. 平台适配

- Codex 与 Claude Code 使用薄 Skill/Agent 适配，调用同一 MCP 或本地接口。
- Cherry Studio 通过 Ollama 进行本地推理，并通过 MCP 使用检索、记忆和受控开发能力。
- Agent Core 提供稳定的本地 MCP，并可补充 OpenAI-compatible 或本地 HTTP 接口。
- 完全离线时，课程索引、已验证缓存、个人记忆和本地项目工具仍可用；易变事实不会伪装成本次已联网验证。

## 14. 分阶段交付

1. **契约冻结**：综合设计、正式训练数据设计、实施计划和作业台账。
2. **正式数据**：至少 300 train，加独立 validation 与 frozen test，生成不可变 release 和安全包。
3. **远程训练**：付费确认、硬件预检、smoke、正式 8B QLoRA、重载与 base 对比。
4. **Mac 模型验收**：Adapter 回收、合并、GGUF/Ollama、真实离线推理。
5. **知识与 RAG**：课程增量索引、Qdrant、BGE-M3、BM25/RRF、强制 Rerank。
6. **Agent 与记忆**：路由、`grill-me`、长期记忆、官方知识回写和受控开发工具。
7. **双编排与前端**：Mastra、Mastra Client、LangGraph 同协议实现。
8. **跨平台验收**：Codex、Claude Code、Cherry Studio 与离线回归。

## 15. 完成标准

只有以下条件全部满足，综合任务才可标为完成：

1. 正式训练 release 至少 300 train，validation/test 独立并通过泄漏检查。
2. NVIDIA CUDA 正式 QLoRA 完成，Adapter 可重载，证据完整。
3. base 与 adapter 冻结测试对比显示可解释提升且无明显退化。
4. M5 24 GB Mac 能通过 GGUF/Ollama 运行并完成真实离线推理验收。
5. 学习笔记可增量索引，RAG 使用混合召回和强制 Rerank，并可展示来源。
6. Mastra Agent、Mastra Client 和 LangGraph 完成同一核心流程。
7. `grill-me`、三轮假设继续、架构顾问和项目执行均通过固定用例。
8. 官方最小知识单元能验证、回写、版本化、过期复核并离线复用。
9. 个人学习记忆能保存、读取、更正、删除和导出，且不污染事实知识。
10. Codex、Claude Code 和 Cherry Studio 调用同一 Agent Core；断网核心能力可用。
11. 原始维修知识场景通过兼容语料演示；实际实现仍明确标注为课程知识助理。
12. 仓库和远程包均不包含凭据、未授权课程原文、个人隐私或模型权重。
