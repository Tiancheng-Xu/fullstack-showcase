## H5 响应式

- 390 × 844：登录、成长、成长记录、时光、百科、我的均已截图。
- 320 × 700：12 个家长端路由的 `scrollWidth === clientWidth`，无页面级横向滚动。
- 产品页底部导航固定在视口底部，主内容底部留白为 96px。
- 登录、注册、建档页无底部导航，主内容底部留白为 40px。
- 详情页采用独立根路由；不再被成长、时光、百科或我的父列表页覆盖。

## 公开百科来源约束

V1 只显示审核过的本地 Mock，不从浏览器直连第三方。后续 Go 后端使用 Provider Adapter：

| 来源 | 用途 | 接入状态 |
| --- | --- | --- |
| 国家卫生健康委员会公开资料 | 中国儿童保健、喂养、免疫口径的首要审核来源 | 公开网页，后端受控采集 |
| 国家人口健康科学数据中心 PHDA | 国内健康科学数据集元数据检索 | API 需申请验证码；非商业转载需注明来源 |
| 《十万个为什么》少儿科普开放平台 | 早教、非医疗少儿科普候选 | API/SDK 需申请试用 |
| PubMed E-utilities | 研究题录与证据链接 | 公开 API；不直接复制论文正文 |

所有文章必须返回来源名称、来源 URL、访问日期、内容审核日期、适龄阶段和免责声明。接口失败时使用最后一次审核缓存；没有审核缓存时显示错误，不把未审核上游内容直接交给家长。
