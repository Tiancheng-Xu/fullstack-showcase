# GTC 2026 Keynote 发布总览

> [!summary] 一句话
> NVIDIA 试图从“卖 GPU”进一步变成 AI 工业体系的总平台：训练、推理、网络、存储、Agent、开放模型、机器人和数字孪生都被纳入同一套基础设施。

## 发布主线

### 1. Agentic AI 基础设施

- Vera Rubin 平台与面向 Agentic AI 的 Vera CPU。
- BlueField-4 STX 存储架构与 DSX AI Factory 参考设计。
- Dynamo 作为 AI Factory 的推理运行与调度系统，重点是把高价值算力稳定转化成 Token。

### 2. Agent 开发平台

- 面向知识工作的开放 Agent 开发平台。
- NemoClaw 面向 OpenClaw 社区，补充可运行的模型与 Agent 能力。
- Nemotron Coalition 与开放模型家族，覆盖 Agentic、Physical 与 Healthcare AI。

### 3. Physical AI

- 面向机器人、Vision AI Agent 和自动驾驶的开放 Physical AI Data Factory Blueprint。
- Omniverse 与 DSX Digital Twin 用于先模拟、验证，再进入真实生产。
- 汽车、制造、通信和空间计算被放入同一条“从数字世界到物理世界”的路线。

## 为什么重要

GTC 给出的判断是：模型进步不再只由参数规模决定。电力、芯片、网络、存储、推理软件、模拟数据和机器人部署能力，将共同决定下一阶段 AI 的速度与成本。
