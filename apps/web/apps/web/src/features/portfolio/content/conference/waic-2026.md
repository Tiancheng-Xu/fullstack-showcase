# WAIC 2026 大会趋势汇总

> [!summary] 一句话
> WAIC 2026 的产业信号是：Agent 开始从聊天界面变成能感知、决策和执行的“数字员工”，同时向端侧、工业现场和物理世界下沉。

## 主要趋势

1. **Agent 成为核心议题**：大会展品和论坛大量围绕智能体，关注点从回答质量转向任务执行与业务闭环。
2. **端侧 AI 落地**：全栈 AI 终端把模型、硬件、应用和交付结合，减少对纯云端调用的依赖。
3. **Physical AI**：可微分物理引擎、世界模型、机器人与自动驾驶共同解决数字模拟到真实环境的迁移。
4. **数据要素 × 行业智能体**：企业真正缺的常常不是模型，而是可用数据、权限、知识底座和业务流程。
5. **AI + 制造**：工业数据集、智能体平台与国产工业软件成为规模化落地抓手。
6. **国产算力协同**：芯片、训练/推理平台与行业应用并行推进，目标是形成能实际交付的完整栈。
