# 吴泳铭：机器智能时代与阿里巴巴全栈 AI 战略路线图

> [!summary] 一句话
> 吴泳铭把 AI 描述为一种将被大规模供给的“机器思考”，并据此提出阿里巴巴以模型、芯片、云为长期基础设施投入方向；他同时判断，机器智能时代真正代表性的产品形态仍未出现。

## 核心论点

### 1. 从“人工智能”转向可规模化供给的机器思考

演讲用工业革命中动力从稀缺能力变成基础供给作类比：AI 的意义不应只按“像不像人”或替代既有脑力任务衡量。讲话提出两个判断：机器可供给的思考总量最终可能远超人类；而机器智能时代的代表性产品还没有出现。AI 编程、写作等更像早期电灯，说明基础能力开始可用，不等于新产品范式已经定型。

讲话还以专业研究资源不足、复杂长期任务等场景说明，便宜而充足的算力可能使大量 Agent 能并行探索过去投入不足的问题。文中“机器思考总量超过人类 1000 倍”“承担 99.9% 思考工作”等属于演讲者的长期预测，不是已验证事实。

### 2. 机器智能需要模型、芯片、云三层基础设施

演讲的战略主线是把 AI 模型、AI 芯片和 AI 云作为相互配合的基础设施。应用层的新产品可能尚不可预见，但其供给规模依赖持续扩大的模型能力、Token 产能和云上运行网络。

### 3. 模型路线：从真实任务反馈走向自我改进与多模态交互

讲话把递归式自我改进（Recursive Self-Improvement, RSI）描述为一条探索路线：模型从真实任务反馈中发现不足、设计实验、构建数据并评价结果，循环推动能力改进。阿里巴巴称 Qwen 团队正在探索这一方向，并计划训练 5–10T 参数规模的新模型；这是公司计划，而非已经交付的模型。

另一条路线是理解与生成一体化的多模态能力，让模型处理声音、图像、表情与动作等输入输出，以支持更自然的感知和交互。

### 4. 芯片路线：以系统协同扩大 Token 产能

演讲将芯片比作机器智能时代的“发电机”，并列出平头哥的真武 GPU、倚天 CPU、磐脉智能网卡与 ICN 互联芯片。讲话称 M890 AI 超节点已支持超过 2 万亿参数模型推理，并宣布真武 V900，给出相对 M890 的性能倍数及单集群规模目标。以上均是发布方陈述，原文未在同页提供独立测试报告、测试配置或口径。

同时，发布方把优化对象描述为芯片、服务器、超节点、网络、模型和推理系统的联合调优，而非只比较单颗芯片峰值性能。

### 5. 云路线：为长时运行的 Agent 提供全球化底座

讲话认为模型训练、持续推理、长任务 Agent 与 AI 开发的软件会长期调用云资源，因此需要围绕这些工作负载设计 AI 云。设想中的云网络需要协同 GPU、CPU、网络、存储、数据库和工具，并覆盖全球。阿里巴巴提出到 2032 年其全球数据中心运营规模超过 20GW 的目标；这是公司目标，不代表当前已建成规模。

### 6. 社会愿景：自动化负担性任务，释放人的创造时间

演讲以工业化、印刷、摄影与录音技术的发展作类比，认为机器承担更多不得不做的任务后，人类会把时间转向创造、探索和审美活动。其核心不是“人类不再重要”，而是机器供给扩大后，人的目标设定与创造力可能获得更大杠杆。

## 技术与战略路线图

```text
真实任务与反馈
       ↓
模型改进 + 多模态感知/交互
       ↓
芯片、服务器、网络、推理系统联合优化
       ↓
全球 AI 云支持持续训练与长时 Agent
       ↓
尚未出现的新产品形态与更广泛的智力供给
```

## 实践启示

1. **基础设施与应用创新要分开评估。** 模型、芯片、云的投资方向可以作为战略假设观察；不能因此推断具体应用已经找到稳定的用户价值。
2. **Agent 的算力评估应采用端到端指标。** 除峰值算力外，还要看有效 Token 吞吐、长任务成功率、故障恢复、服务延迟、单位任务成本与能耗。
3. **RSI 需要闭环证据。** 应追踪模型能否自主产生可验证实验、提高数据质量、准确评价结果，并在独立留出任务上持续改进；仅有“能自我改进”的路线描述不够。
4. **多模态能力要落到交互任务。** 评估感知、状态跟踪、动作选择、用户纠错与安全中断是否形成可靠闭环，而不仅比较生成效果。
5. **长时间运行的 Agent 需要云平台级治理。** 身份、权限、状态持久化、审计、预算、数据边界与人工接管机制应和算力一起设计。
