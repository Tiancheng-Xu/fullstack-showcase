# cosmos-local-chain - 需求规格

## 目标

新增一条可在本机重复启动的 Cosmos SDK 教学链，完整展示创世账户分发、验证人、Alice 向 Bob 转账、交易查询和持续出块，同时保持 BabySteps 既有 Sepolia RPC 与 The Graph 成果不变。

## 功能需求

1. 使用 Ignite CLI `v29.8.0` 和 Cosmos SDK `v0.53` 系列生成可审阅的 Go 链源码。
2. 链 ID 固定为 `babysteps-local-1`，地址前缀为 `baby`，基础代币为 `ubaby`。
3. 创世状态包含 `validator`、`alice`、`bob` 三个角色及明确余额。
4. 提供本地安装、启动、转账演示、停止和证据导出命令。
5. 演示必须查询真实交易和包含该交易的区块，并证明高度继续增加。
6. 运行时密钥、助记词、私钥、PID、日志和可重建目录不得进入 Git。
7. BabySteps 通过提交 `d728315f1c34bd76377f2b302f9cc6f1ed9e3167` 只读复用，不复制或修改其 Web3 文件。
8. 不部署公开网络，不创建云资源，不使用付费 RPC，不推送发布。

## 验收标准

- [ ] 本地链可通过文档中的固定命令从干净状态启动。
- [ ] 三个创世角色均有公开地址和预期 `ubaby` 初始余额。
- [ ] Alice 向 Bob 的真实转账成功，交易返回码为 0，Bob 余额按转账额增加。
- [ ] 可按交易哈希查询交易，并能查询包含该交易的区块。
- [ ] 等待后最新区块高度增长，证明验证人持续出块。
- [ ] 失败路径能退出并清理本项目节点，不误停其他进程。
- [ ] 公开证据不包含助记词、私钥、密钥环内容或本机秘密。
- [ ] BabySteps 既有 Sepolia RPC 与 The Graph 文件保持未修改。
